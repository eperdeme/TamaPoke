Older saves keep their boxed Pokemon when upgrading.

Back up before installing. There are no changes to gameplay, balance or controls, and no factory reset is needed.

## Older Save Upgrades
- Converting an older party could save an empty box before the boxed Pokemon had been loaded. The party survived, but the box could then appear empty and stay that way after restarting.
- The upgrade now loads both the party and the box before saving their converted contents together.
- This protects older saves and backups that still need conversion. Saves already using the current record layout do not need this conversion.
- This update does not automatically recover a box that was already recorded as empty. Keep any backup made before the problem occurred; installing this update is not a recovery operation.

## Additional Checks
- Release checks now run compatible tests on an emulated ESP32-S3, including real save storage, older-save upgrades, reboot persistence and watchdog detection.
- The existing battle-exit, audio and touch checks remain in place. These automated checks do not replace testing on a physical board.

The save format is unchanged. Downgrading remains unsupported.
