A hardening release. **Nothing behaves differently, and there is no bug here that anyone could have hit** — if you are on v3.20 there is no urgency in taking it.

It closes the last remaining instance of the fault behind [#4](https://github.com/eperdeme/TamaPoke/issues/4), found while writing that fix up rather than reported.

## Gym region handling

- The team-select screen now remembers which region's gym it was opened for. It previously read the region from the gym menu every time it needed it, so the hard-mode team-size limit and the leader named at the top of the screen were answered from wherever the menu happened to be pointing rather than from the gym you had actually chosen.
- Confirming a fight now explicitly fights the region the team-select screen showed you, so the team limit you were given, the leader you were shown and the ladder the badge is filed under cannot disagree.

This was **not reachable in v3.20**. Every gesture that could move the gym menu already checks for the team-select screen first and backs out of it instead, so the menu could not move underneath it. The fix is here because that protection is an ordering that has to keep being true, and this is the same missing-snapshot mistake that put Brock's Onix into every region's gym — one screen earlier, and one dispatch-order change away from mattering.

A regression test now opens the picker on one region's gym, moves the menu underneath it to a region whose first gym fields a different number of creatures, and asserts the limit does not follow. It picks that second region by searching for one that actually differs instead of naming it, because the obvious pair (Johto and Kalos) both field two and made the test pass whether the fix was present or not.
