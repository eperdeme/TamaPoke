# No more black screen flashes, cleaner boot, and Dutch language

- **Fixed brief black screen flashes on touch.** Tapping or releasing the screen
  could briefly drop brightness almost to black for a frame, sometimes stalling
  a save mid-tap or swallowing a quick follow-up tap. Touch interactions now
  keep the screen steadily lit.
- **Cleaner startup.** The screen now stays dark until the first real frame is
  ready instead of briefly flashing uninitialized display memory while the
  device boots.
- **More resilient power button handling.** Brief communication glitches on the
  shared bus can no longer be mistaken for a power button press or low-battery
  event, preventing unexpected screen-offs.
- **Dutch (NL) UI language.** Dutch is now available as the seventh language in
  Settings, alongside Spanish, English, French, German, Italian, and Portuguese.

Your save is kept automatically and no reset or migration is needed. Before
installing, download and keep a backup, leave **Erase device** unchecked, and
keep power connected until installation finishes. This version passed the
emulator tests and firmware build; it has not been tested on a physical board.
